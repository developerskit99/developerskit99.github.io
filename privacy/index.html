Privacy Policy

Short version: everything you do with our tools stays in your browser. No uploads, no accounts, no tracking of your input. Anonymous page-view analytics help us understand traffic patterns.

What we collect

Nothing. We do not collect, store, or transmit anything you type, paste, or upload into the tools. All processing happens locally on your device using JavaScript.

Cookies and tracking

We do not set cookies and we do not run advertising or tracking scripts. We use Google Analytics for anonymous page-view statistics only, which does not track your tool input.

Hosting

This site is hosted on GitHub Pages. GitHub may collect standard server logs (such as IP addresses) as described in the GitHub Privacy Statement. We do not have access to those logs.

Third parties

We do not share data with third parties because we do not collect any data in the first place.

Contact

Questions about this policy? Open an issue at our GitHub repository.

FAQ

Does DevelopersKit collect my data?

No. All tool processing happens locally in your browser using JavaScript. We do not collect, store, or transmit anything you type, paste, or upload into the tools.

Does DevelopersKit use cookies or analytics?

We use Google Analytics to measure anonymous page views (no cookies, no personally identifiable data). We do not run advertising or tracking scripts, and no tool input is ever sent to any server.

What about hosting logs?

This site is hosted on GitHub Pages. GitHub may collect standard server logs (such as IP addresses) as described in the GitHub Privacy Statement. We do not have access to those logs.

How can I contact you about privacy?

Open an issue on our GitHub repository: https://github.com/developerskit99/developerskit99.github.io.
