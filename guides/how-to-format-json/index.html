How to Format JSON Online

Raw JSON from an API is unreadable until formatted. Learn what JSON formatting does, how validation works, and how to pretty-print any payload with our free tool.

What JSON formatting means

Formatting (pretty-printing) takes compact JSON like {"a":1} and expands it with indentation so humans can read nested objects and arrays at a glance.

Format vs minify vs validate

Format for reading, minify for shipping (smaller files, faster APIs), validate for debugging. The three tools below cover each job.

Common errors and fixes

Missing commas between fields, single quotes instead of double quotes, and trailing commas are the top three causes of invalid JSON. Paste the payload into the formatter to pinpoint each one.

FAQ

What does a JSON formatter do?

It parses raw JSON and re-prints it with indentation and line breaks, and reports syntax errors with their location when the input is invalid.

Why is my JSON not formatting?

Almost always a syntax mistake: missing comma, unquoted key, or trailing comma. The validator message shows the exact position to fix.

Is formatting the same as validating?

No. Formatting pretty-prints valid JSON; validation checks whether it is valid at all. Use the validator first, then format.

Is my JSON uploaded anywhere?

No. Formatting runs entirely in your browser using JavaScript. Your data never leaves your device.
