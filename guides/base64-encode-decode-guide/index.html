How it works

Three bytes (24 bits) split into four 6-bit groups, each mapped to a letter, digit, + or /. Padding = signs fill the last block.

Where you meet it

Email attachments (MIME), data-URLs in CSS, JWT tokens, and API payloads carrying images are all Base64 in the wild.

Encoding is not encryption

Base64 provides zero secrecy. For passwords and tokens use real hashing (see the hash generator) and HTTPS transport.

FAQ

What is Base64 encoding?

A way to represent binary data using 64 safe ASCII characters, so images or files can travel inside text formats like JSON, email, or URLs.

Is Base64 encryption?

No. It is encoding, not encryption - anyone can decode it instantly. Never use it to hide secrets or passwords.

Why is Base64 output longer?

Every 3 input bytes become 4 output characters, so encoded data is about 33% larger than the original.

Is my data uploaded?

No. Encoding and decoding happen entirely in your browser.
